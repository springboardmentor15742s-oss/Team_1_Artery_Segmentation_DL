
# Artery Segmentation and Stenosis Detection Using Advanced Deep Learning Techniques

## Overview
An AI-powered medical image analysis system designed to automatically segment arteries, identify abnormal arterial regions, detect and localize stenosis, and estimate the severity of arterial narrowing using advanced deep learning techniques.

The system aims to assist clinicians and medical imaging specialists through automated analysis and quantitative assessment of vascular structures.

## Objectives
- Automated artery segmentation and vessel structure extraction.
- Stenosis detection and localization.
- Estimation of arterial narrowing percentage.
- Severity-based stenosis classification.
- Visualization of segmented arteries and stenotic regions.
- Explainable AI for model interpretability.
- Quantitative evaluation of model performance.

## Key Modules
- User Authentication and Case Management
- Medical Image Upload and Preprocessing
- Artery Segmentation
- Vessel Structure and Centerline Analysis
- Stenosis Detection and Localization
- Stenosis Severity Assessment
- Deep Learning Model Training and Evaluation
- Explainable AI and Visualization
- Medical Image Analysis Dashboard
- Report Generation and Model Management
- Testing, Integration and Deployment

## Technology Stack

- **Programming:** Python
- **Backend:** FastAPI, REST APIs, Pydantic, SQLAlchemy
- **Frontend:** React.js, JavaScript/TypeScript, Tailwind CSS
- **Database:** PostgreSQL, MongoDB
- **Deep Learning:** PyTorch, TensorFlow, MONAI
- **Image Processing:** OpenCV, SimpleITK, NiBabel, pydicom
- **ML Libraries:** NumPy, Pandas, Scikit-learn
- **Segmentation Models:** U-Net, U-Net++, Attention U-Net, DeepLabV3, nnU-Net, TransUNet
- **Explainable AI:** Grad-CAM, Captum
- **Deployment:** Docker, AWS / Azure
- **Version Control:** Git and GitHub

## Evaluation Metrics

**Segmentation:** Dice Score, IoU, Precision, Recall, Sensitivity, Specificity, Hausdorff Distance.

**Stenosis Detection:** Accuracy, Precision, Recall, F1-score, AUC-ROC, False Positive Rate.

**Severity Classification:** Macro F1-score, Weighted F1-score, Confusion Matrix.

**System Performance:** Inference Time, API Response Time, Processing Time.
